# Original research illustrations

Created with the built-in ImageGen tool for the three Research interests cards. These are conceptual illustrations, not photographs of the author's hardware or figures from a paper. All images use a matching silver/charcoal/teal palette, pale mint studio background, and soft shadows. Web assets are 800 × 600 WebP exports; source images are retained in the generation archive.

- `gripper-original.webp`: adaptive two-finger gripper holding a rounded object.
- `motion-planning-original.webp`: robotic arm following a curved trajectory around an obstacle.
- `robot-learning-original.webp`: learned manipulation with an abstract neural-network motif.

The exact prompt set is documented in `generation-prompts.md`.
